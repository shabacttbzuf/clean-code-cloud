# نظام التصميم المركزي UI/UX 1.0

> مرجع تنفيذي للمكونات والأنماط. لا يغيّر الهوية الوظيفية أو الصلاحيات ولا يفرض إعادة بناء الصفحات المكتملة.

## الهوية المعتمدة

| الدور | القيمة | الاستخدام |
|---|---|---|
| كحلي العلامة | `#102b4e` | اللون الأساسي والعناوين والعناصر ذات الأولوية |
| ذهبي العلامة | `#d6ad55` | التمييز والعناصر الثانوية المهمة، وليس للنصوص الصغيرة فوق الأبيض |
| أبيض العلامة | `#ffffff` | الأسطح والبطاقات والمساحات المقروءة |

تظل الألوان الدلالية مثل النجاح والتحذير والخطر مستقلة عن ألوان العلامة.

## الخطوط والاتجاه

- العربية: Cairo محمّل محلياً من Fontsource.
- اللاتينية والأرقام/المعرفات: Inter.
- اتجاه التطبيق الافتراضي RTL من عنصر HTML الجذري.
- استخدم خصائص CSS المنطقية مثل `margin-inline` و`padding-inline` و`text-align: start`.
- المحتوى المختلط (البريد، الهاتف، الروابط، الأكواد) يحدد `dir="ltr"` عند الحاجة على العنصر نفسه.

## Design Tokens

- المصدر الوحيد لقيم الألوان الدلالية وأنصاف الأقطار والظلال هو `src/styles.css`.
- `src/lib/design-tokens.ts` واجهة TypeScript مرجعية للتوكنات، ولا يعيد تعريف القيم.
- لا تدخل ألوان العلامة مباشرة داخل المكونات عند وجود token دلالي مناسب.
- ألوان الحالة تبقى `success` و`warning` و`destructive`.

## المكونات المشتركة

المكونات الأساسية الموجودة مسبقاً في `src/components/ui` هي المصدر المعتمد للأزرار والبطاقات والحقول والنوافذ والقوائم والجداول والنماذج. لا تنشئ نسخة موازية منها.

المكونات الإضافية:
- `AppIcon`: غلاف موحد لأيقونات Lucide مع دعم إخفائها عن قارئ الشاشة عندما تكون زخرفية.
- `PageSection`: حاوية تخطيط مرنة لصفحات الأقسام.
- `SectionHeading`: عنوان ووصف وإجراءات القسم مع التفاف مناسب للهاتف.
- `Surface`: سطح محتوى بحدود وظلال وزوايا موحدة.
- `ResponsiveTableContainer`: حاوية جدول قابلة للتمرير أفقياً.

## قواعد التفاعل وإمكانية الوصول

- لا تزل مؤشرات التركيز المرئية؛ استخدم `:focus-visible`.
- احترم `prefers-reduced-motion`.
- لا تعتمد على اللون وحده لشرح حالة أو خطأ.
- حافظ على حالات disabled وloading وvalidation الحالية.
- الأيقونة الزخرفية لا تُقرأ صوتياً.
- لا تفرض عرضاً أدنى على جميع الجداول؛ اسمح بالتمرير عند الحاجة.

## الاستجابة

- التخطيط بعرض مرن و`min-width: 0` لتفادي تمدد الحاويات.
- الجداول داخل حاويات قابلة للتمرير دون فرض تمرير أفقي على مستوى الصفحة.
- النوافذ محدودة بارتفاع نافذة العرض وتسمح بالتمرير الداخلي.
- راعِ safe-area على الهواتف وأهداف اللمس.
- قواعد CSS وحدها لا تثبت اختباراً بصرياً فعلياً.

## حدود هذه الدفعة

لم تُعدّل ملفات الشريط العلوي أو التبويبات أو الصفحة الرئيسية. لم تتغير بيانات أو مخططات أو صلاحيات أو تدفقات أعمال. تطبيق المكونات الجديدة على الصفحات القائمة تدريجي عند صيانة كل صفحة، دون استبدال شامل قد يغيّر سلوكها.
