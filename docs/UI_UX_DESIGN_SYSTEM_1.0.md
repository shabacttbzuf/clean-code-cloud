# نظام التصميم المركزي UI/UX 1.0

> مرجع تنفيذي للمكونات والأنماط الجديدة. هذا الملف لا يغيّر الهوية الوظيفية أو صلاحيات النظام ولا يفرض إعادة بناء الصفحات المكتملة.

## الهوية المعتمدة

| الدور | القيمة | الاستخدام |
|---|---|---|
| كحلي العلامة | `#102b4e` | اللون الأساسي والعناوين والعناصر ذات الأولوية |
| ذهبي العلامة | `#d6ad55` | التمييز والعناصر الثانوية المهمة، وليس للنصوص الصغيرة فوق الأبيض |
| أبيض العلامة | `#ffffff` | الأسطح والبطاقات والمساحات المقروءة |

تظل الألوان الدلالية مثل النجاح والتحذير والخطر مستقلة عن ألوان العلامة حتى لا تختلط دلالات الحالات مع الهوية.

## الخطوط والاتجاه

- العربية: Cairo بأوزان 400 و500 و600 و700، محمّلة محلياً من Fontsource.
- اللاتينية والأرقام/المعرفات: Inter، مع الحفاظ على الأرقام الجدولية.
- اتجاه التطبيق الافتراضي RTL من عنصر HTML الجذري.
- استخدم خصائص CSS المنطقية مثل `margin-inline` و`padding-inline` و`text-align: start` بدلاً من left/right متى كان المقصود اتجاه المحتوى.
- المحتوى المختلط (البريد، الهاتف، الروابط، الأكواد) يحدد `dir="ltr"` عند الحاجة على العنصر نفسه، لا على الصفحة كاملة.

## Design Tokens

- المصدر الوحيد لقيم الألوان الدلالية وأنصاف الأقطار والظلال هو `src/styles.css`.
- `src/lib/design-tokens.ts` واجهة TypeScript مرجعية للتوكنات، ولا يعيد تعريف القيم.
- يمنع إدخال ألوان العلامة مباشرة داخل المكونات عند وجود token دلالي مناسب.
- ألوان الحالة تبقى `success` و`warning` و`destructive` ولا تستبدل بالذهبي.

## المكونات المشتركة

المكونات الأساسية الموجودة مسبقاً في `src/components/ui` هي المصدر المعتمد للأزرار والبطاقات والحقول والنوافذ والقوائم والجداول والنماذج. لا تنشئ نسخة موازية منها.

المكونات الإضافية الجديدة:
- `AppIcon`: غلاف موحد لأيقونات Lucide، بحجم افتراضي ثابت، مع دعم إخفائها عن قارئ الشاشة عندما تكون زخرفية.
- `PageSection`: حاوية تخطيط مرنة لصفحات الأقسام.
- `SectionHeading`: عنوان ووصف وإجراءات القسم مع التفاف مناسب للهاتف.
- `Surface`: سطح محتوى بحدود وظلال وزوايا موحدة.
- `ResponsiveTableContainer`: حاوية جدول قابلة للتمرير أفقياً.

مكون `Table` الأساسي يضيف علامة سطح الجدول تلقائياً حتى تستفيد الجداول الحالية من طبقة التناسق دون تغيير طريقة استخدامها.

## قواعد التفاعل وإمكانية الوصول

- لا تزل مؤشرات التركيز المرئية؛ استخدم `:focus-visible`.
- احترم `prefers-reduced-motion`.
- لا تعتمد على اللون وحده لشرح حالة أو خطأ.
- حافظ على حالات disabled وloading وvalidation الحالية.
- أيقونات Lucide موحدة الحجم ومحاذاة baseline؛ الأيقونة الزخرفية لا تُقرأ صوتياً.
- لا تفرض عرضاً أدنى على جميع الجداول؛ يسمح للجدول بالتمرير بدلاً من ضغط الأعمدة.

## الاستجابة

- التخطيط بعرض مرن و`min-width: 0` لتفادي تمدد الحاويات.
- الجداول داخل حاويات قابلة للتمرير، ولا تجبر الشاشة على تمرير أفقي على مستوى الصفحة.
- النوافذ محدودة بارتفاع نافذة العرض وتسمح بالتمرير الداخلي.
- راعِ safe-area على الهواتف وأهداف اللمس.
- اختبر أحجام الهاتف واللوحي وسطح المكتب، مع عدم اعتبار قواعد CSS وحدها دليلاً على اختبار بصري فعلي.

## حدود هذه الدفعة

لم تُعدّل ملفات الشريط العلوي أو التبويبات أو الصفحة الرئيسية. لم تتغير بيانات أو مخططات أو صلاحيات أو تدفقات أعمال. تطبيق المكونات الجديدة على كل صفحة قائمة يتم تدريجياً عند صيانة الصفحة، ولا يُجرى استبدال شامل آلي قد يغيّر سلوكها.
