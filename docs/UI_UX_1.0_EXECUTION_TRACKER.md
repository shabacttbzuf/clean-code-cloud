## قواعد لا يجوز تجاوزها

1. عدم حذف أي ميزة أو مسار قائم.
2. عدم حذف أو تعديل بيانات الإنتاج.
3. عدم تغيير أسماء الجداول أو المسارات إلا لضرورة موثقة وتوافق خلفي.
4. عدم إضعاف RLS أو صلاحيات الخادم أو حماية Super Owner.
5. عدم تعديل أثر العمليات المالية أو المخزنية بسبب تحسين الواجهة.
6. كل زر أو إجراء جديد يجب أن يؤدي وظيفة حقيقية، مع احترام الصلاحيات على الواجهة والخادم وقاعدة البيانات.
7. تجهيز ترحيلات جديدة فقط عند ثبوت الحاجة، وعدم تعديل الترحيلات المطبقة سابقاً.
8. لا تطبيق على قاعدة الإنتاج قبل مراجعة SQL وآثاره وخطة الرجوع.
9. يُنفذ تحقق موجّه لكل دفعة/مرحلة (مراجعة التغييرات، اختبارات الوحدة المناسبة، وفحص السلوك المتأثر متى أمكن). وتُنفذ دورة الاختبارات الشاملة النهائية في المرحلة 17 بعد اكتمال المراحل 1–16؛ لا يُعلن نجاح أي فحص لم يُنفذ.
