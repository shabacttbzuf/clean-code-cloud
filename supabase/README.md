# Supabase database migrations

ملفات `migrations/` هي سجل تغييرات مخطط قاعدة البيانات. يجب أن تبقى الملفات التاريخية كما هي بعد تطبيقها؛ أضف ملفات ترحيل جديدة لأي إصلاح.

لإعادة إنشاء قاعدة جديدة، راجع `../docs/REBUILD_DATABASE.md`. لا تنفذ `supabase db push` على قاعدة الإنتاج أثناء أعمال الإصلاح، ولا تستخدم قاعدة تحتوي بيانات تريد الاحتفاظ بها كتجربة.

ملف `drizzle/schema.ts` ليس مصدر المخطط في النسخة الحالية؛ محتواه يصرّح بأنه فارغ عمداً. مصدر المخطط المعتمد حالياً هو ترحيلات Supabase، إلى أن يتم توثيق قرار معماري مختلف واختباره.
